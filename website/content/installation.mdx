# Install

tsp is one binary with two halves. Set up the half you need, or both: they don't depend on each other.

| You want | Set up | Takes |
| --- | --- | --- |
| `https://<name>.localhost` on this machine | [Local HTTPS](#2-local-https-once-per-machine) | one command, one password prompt |
| A link that works from anywhere (webhooks, callbacks, sharing) | [Tailscale](#3-tailscale-for-online-links) | a free Tailscale account, two switches in its admin console |

## 1. Install tsp

<Tabs items={["Homebrew", "npm", "Go", "No install"]}>
  <Tabs.Tab>
    ```bash
    brew install meabed/tap/tsp
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    npm i -g tailscale-proxy        # the command is still tsp; a small Node launcher runs it
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    go install github.com/meabed/tailscale-proxy@latest
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    npx tailscale-proxy doctor      # any command, without installing
    ```
  </Tabs.Tab>
</Tabs>

Homebrew is the lightest on macOS and Linux: the binary runs directly, with no Node process beside each `tsp run`.
macOS, Linux, Windows and WSL, on amd64 and arm64. Prefer a window to a terminal? The [desktop app](/desktop) shares
dev servers from the menu bar.

## 2. Local HTTPS, once per machine

```bash
tsp service install
```

```
✓ boot service /Library/LaunchDaemons/com.meabed.tailscale-proxy.plist
✓ proxy running (tsp 1.11.0, pid 57001, port 443)
✓ local CA trusted by the OS
```

It starts the local proxy at boot and adds its certificate authority to the system's trust store, so browsers, curl,
Bun and Node accept `https://<name>.localhost`. It asks for your password only when the boot service itself changes:
the first time, and after a tsp update. Running it again is always safe; it checks what is in place and fixes only what
is missing. `tsp service status` prints the same three lines and exits 1 if any is off.

Then run an app at its name: [Local HTTPS names](/local-https).

## 3. Tailscale, for online links

[Tailscale](https://tailscale.com) carries the online links: it gives your machine a stable name and a certificate, and
its Funnel feature makes a port reachable from the internet. The free plan is enough.

<Tabs items={["macOS", "Linux", "Windows"]}>
  <Tabs.Tab>
    ```bash
    brew install --cask tailscale    # or the app from tailscale.com/download
    tailscale up                     # sign in in the browser
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    curl -fsSL https://tailscale.com/install.sh | sh
    sudo tailscale up
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```powershell
    winget install tailscale.tailscale
    tailscale up
    ```
  </Tabs.Tab>
</Tabs>

Two switches in the [admin console](https://login.tailscale.com/admin), once per Tailscale network:

1. **DNS:** turn on MagicDNS and HTTPS Certificates ([guide](https://tailscale.com/kb/1153/enabling-https)).
2. **Access controls:** allow Funnel, which public links need ([guide](https://tailscale.com/kb/1223/funnel)):
   ```jsonc
   { "nodeAttrs": [{ "target": ["autogroup:member"], "attr": ["funnel"] }] }
   ```

<Callout type="info">
  Links only for your own devices and teammates on your Tailscale network don't need step 2: use `tsp --private`.
</Callout>

Check both halves at once:

```bash
tsp doctor
```

```
Tailscale (tsp start: https://<node>.ts.net/<project>)
✓ tailscale installed  (1.104.7)
✓ tailscale up
✓ funnel enabled
✓ service discovery  (6 service(s) in 3000-6000)

Local HTTPS names (tsp run: https://<name>.localhost)
✓ boot service /Library/LaunchDaemons/com.meabed.tailscale-proxy.plist
✓ proxy running (tsp 1.12.0, pid 57001, port 443)
✓ local CA trusted by the OS

All checks passed: `tsp start` exposes your servers, `tsp run` serves an app at https://<name>.localhost.
```

Each ✗ is followed by the command that fixes it, and the last line says which half is ready. Then share your dev servers: [Share online](/share).

## Update and remove

```bash
tsp update                 # the latest release: runs brew or npm itself when that is how tsp was installed
tsp service install        # after an update: moves the boot service to the new version
tsp service uninstall      # stop and remove the boot service
```

To remove the local certificate authority as well, delete `~/.tailscale-proxy/ca` and remove the "tailscale-proxy local
CA" certificate from the trust store (Keychain Access on macOS).
