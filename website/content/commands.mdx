# Commands

Every command prints what to do next when something is off. `tsp <command> --help` lists its flags; `-v` prints the
version.

## Both halves

| Command | What it does |
| --- | --- |
| `tsp doctor` | Check Tailscale and local HTTPS; each ✗ with the command that fixes it; exit 1 when one fails |
| `tsp update` | Update to the latest release, the way tsp was installed (brew, npm or the binary itself, checksum-verified) |
| `tsp stats [--since 24h] [--json]` | How the local proxy runs: health, updates, and requests, failures and p50/p95/p99 per name ([Logs and stats](/logs-and-stats)) |
| `tsp logs [-n 40] [-f] [--json]` | The local proxy's events: starts, live updates, rollbacks, failed or slow requests |
| `tsp uninstall [--yes] [--all]` | Remove everything tsp set up: the Tailscale entry it created, the boot service, the CA and `~/.tsp`; `--all` also the config and a standalone binary |

## Local HTTPS names

| Command | What it does |
| --- | --- |
| `tsp run` | Run the app in this folder at `https://<name>.localhost`, from package.json `"tsp": { "name", "script" }` |
| `tsp run <name> -- <cmd...>` | Run any command at `https://<name>.localhost` |
| `tsp run --force` | Take a name over from a run in another terminal |
| `tsp routes [--json]` | The names running now, with port, process and folder |
| `tsp service install` | Once per machine (your password once): the proxy from boot, its CA trusted; it updates itself afterwards. Safe to repeat |
| `tsp service status` | Three ✓/✗ lines; exit 1 when one is off |
| `tsp service uninstall` | Stop and remove the boot service |
| `tsp trust` | Trust the local CA only |
| `tsp proxy [--port n]` | The proxy in the foreground (what the boot service runs) |

## Online links through Tailscale

| Command | What it does |
| --- | --- |
| `tsp` | `tsp start` with your saved settings: share every dev server found |
| `tsp start [flags]` | Find dev servers, run the routing proxy, publish it through Funnel or Serve |
| `tsp list` | What would be shared, with each link, without sharing |
| `tsp status` | The Funnel or Serve entry, the current map, and requests per project in the last hour |
| `tsp reset` | Remove the Funnel or Serve entry (`--private` for Serve) |
| `tsp configure [flags]` | Save flags as defaults in `~/.tsp/config.json` |

## `start` flags

Defaults come from your config file (see [Configuration](/configuration)).

| Flag | Default | Meaning |
| --- | --- | --- |
| `--ports <lo-hi\|port>` | `3000-6000` | Port range **or a single port** to scan |
| `--all` | off | Include all listeners, not just web runtimes |
| `--runtimes <list>` | all known | Restrict to specific runtimes, e.g. `node,bun,python` |
| `--docker` | off | Also discover Docker containers via the local Docker API (read-only) |
| `--private` | off | Expose privately via Tailscale **Serve** (default: **Funnel**) |
| `--bind <addr>` | `127.0.0.1` | Listen address; `0.0.0.0` to reach from containers/LAN |
| `--port <n>` | `18443` | Local proxy HTTP port (never a Funnel port: Tailscale.app's Serve binds that port on every address) |
| `--interval <sec>` | `20` | Re-scan period |
| `--https-port <n>` | `443` | Public/tailnet HTTPS port (Funnel: `443`/`8443`/`10000`) |
| `--deregister-cycles <n>` | `5` | Missing scans before a gone service is removed |
| `--forward-host` | off | Forward the public host to apps via `X-Forwarded-Host/Proto` (default: local) |
| `--match-separators` | on | Route `/a-b/` and `/a_b/` alike; `--match-separators=false` for exact-dash |
| `--accept-dns <bool>` | unset | Optionally `tailscale set --accept-dns` on start; `false` lets a tailnet host resolve the public funnel name (persists) |
| `--bg` | off | Run detached (logs → `./tsp.log`) |
| `--proxy-only` | off | Run the proxy only; print the `tailscale` command |
| `--log-requests` | on | Log each proxied request |
| `--quiet` | off | Disable per-request logging |

## Startup output

On start, `tsp` prints the effective parameters and logs discoveries:

```
Using config: /Users/me/.tsp/config.json
  ports=3000-6000  mode=public (Funnel)  proxy=127.0.0.1:18443  https=443
  interval=20s  runtimes=default (…)  deregister-after=5 scans  log-requests=true
  host=local (apps see localhost)

2026/05/31 02:05:48 discovered web   node   :4983  pid 15588  ~/work/help-ai/apps/web
2026/05/31 02:05:49 200 GET    /web/ → 127.0.0.1:4983 (6ms)
```

Request logs are colorized by status on a terminal (set `NO_COLOR` to disable).

## One-liners

```bash
tsp list                       # what's discoverable + the public URLs
tsp reset                      # take the Funnel down (tsp reset --private for Serve)
tsp --ports 4000               # scan a single port
tsp --interval 5               # faster pickup of new servers
tsp --proxy-only               # local proxy only; print the tailscale command
tsp --bg                       # run detached; logs → ./tsp.log
tsp --forward-host             # send the public host to apps
tsp --match-separators=false   # exact-dash routing (default treats - and _ alike)
```
